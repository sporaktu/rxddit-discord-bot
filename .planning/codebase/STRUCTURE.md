# Codebase Structure

**Analysis Date:** 2025-01-11

## Directory Layout

```
rxddit-discord-bot/
├── src/                    # TypeScript source files
├── dist/                   # Compiled JavaScript output
├── tests/                  # Jest test files
├── k8s/                    # Kubernetes manifests
├── scripts/                # Deployment automation
├── .github/workflows/      # CI/CD pipeline definitions
├── data/                   # SQLite database (runtime, gitignored)
├── package.json            # Project manifest
├── tsconfig.json           # TypeScript configuration
├── jest.config.js          # Test runner configuration
├── Dockerfile              # Multi-stage Docker build
├── docker-compose.yml      # Local container orchestration
└── README.md               # User documentation
```

## Directory Purposes

**src/**
- Purpose: TypeScript source code
- Contains: Main bot logic, database abstraction, utilities
- Key files:
  - `bot.ts` - Main entry point, Discord event handlers
  - `database.ts` - SQLite wrapper class
  - `linkUtils.ts` - URL detection and conversion
- Subdirectories: None (flat structure)

**dist/**
- Purpose: Compiled JavaScript output
- Contains: `.js`, `.d.ts`, `.js.map` files
- Generated by: `npm run build` (TypeScript compiler)
- Key files: `bot.js` (production entry point)

**tests/**
- Purpose: Jest test suite
- Contains: Unit and integration tests
- Key files:
  - `linkUtils.test.ts` - URL detection/conversion tests
  - `database.test.ts` - Database operations tests
  - `integration.test.ts` - End-to-end workflow tests
  - `setup.ts` - Test environment configuration

**k8s/**
- Purpose: Kubernetes deployment manifests
- Contains: YAML resource definitions
- Key files:
  - `deployment.yaml` - Pod/Deployment spec
  - `pvc.yaml` - Persistent Volume Claim for database

**scripts/**
- Purpose: Deployment automation scripts
- Contains: Shell scripts for CI/CD
- Key files:
  - `deploy-to-k8s.sh` - Kubernetes deployment script
  - `rollback.sh` - Rollback script

**.github/workflows/**
- Purpose: GitHub Actions CI/CD pipelines
- Contains: YAML workflow definitions
- Key files:
  - `docker-build.yml` - Build and push Docker images
  - `deploy.yml` - Manual Kubernetes deployment

## Key File Locations

**Entry Points:**
- `src/bot.ts` - Main application entry
- `dist/bot.js` - Production entry (compiled)

**Configuration:**
- `tsconfig.json` - TypeScript compiler options
- `jest.config.js` - Test runner configuration
- `.env.example` - Environment variable template
- `docker-compose.yml` - Local Docker stack

**Core Logic:**
- `src/bot.ts` - Discord event handling, message processing
- `src/database.ts` - SQLite operations, data persistence
- `src/linkUtils.ts` - Reddit URL detection and conversion

**Testing:**
- `tests/*.test.ts` - Test files
- `tests/setup.ts` - Test utilities

**Documentation:**
- `README.md` - User-facing installation and usage guide
- `KUBERNETES_DEPLOYMENT_PLAN.md` - K8s deployment details
- `SHARED_TASK_NOTES.md` - Development notes

## Naming Conventions

**Files:**
- `camelCase.ts` - TypeScript source modules
- `kebab-case.test.ts` - Test files
- `UPPERCASE.md` - Important documentation files
- `kebab-case.yml` - YAML configurations

**Directories:**
- lowercase - All directories (`src`, `dist`, `tests`, `k8s`)
- Plural for collections - `tests/`, `scripts/`

**Special Patterns:**
- `*.test.ts` - Jest test files
- `*.d.ts` - TypeScript declaration files
- `.env*` - Environment configuration files

## Where to Add New Code

**New Feature:**
- Primary code: `src/` directory
- Tests: `tests/{feature}.test.ts`
- If new integration: Update `INTEGRATIONS.md`

**New Discord Event Handler:**
- Implementation: `src/bot.ts` (add event listener)
- Tests: Currently not covered (Discord.js mocking needed)

**New Utility Function:**
- Implementation: `src/linkUtils.ts` (or new `src/{name}Utils.ts`)
- Tests: `tests/{name}Utils.test.ts`

**New Database Operation:**
- Implementation: `src/database.ts` (add method to MessageDatabase)
- Tests: `tests/database.test.ts`

**Kubernetes Resources:**
- Implementation: `k8s/{resource}.yaml`
- Documentation: Update `KUBERNETES_DEPLOYMENT_PLAN.md`

## Special Directories

**dist/**
- Purpose: Build output
- Source: Generated by TypeScript compiler
- Committed: No (gitignored)

**data/**
- Purpose: SQLite database storage
- Source: Created at runtime
- Committed: No (gitignored)

**node_modules/**
- Purpose: npm dependencies
- Source: Installed by `npm install`
- Committed: No (gitignored)

**.planning/**
- Purpose: Project planning documents
- Source: Manual/generated documentation
- Committed: Yes
